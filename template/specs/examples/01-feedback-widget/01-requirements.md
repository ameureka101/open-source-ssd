# 01-Requirements: 功能需求与验收标准

## 1. 用户故事 (User Stories)
* 作为一个访问者，我可以在页面右下角点击「反馈」按钮展开卡片，输入我的使用体验并提交。
* 作为一个开发者，我可以在后台或数据库中查阅包含评分、文本、提交时间与页面 URL 的结构化反馈记录。

## 2. 验收判据 (Acceptance Criteria)
- [ ] **AC-1**：未输入文本或未选择星级时，「提交」按钮处于 disabled 状态。
- [ ] **AC-2**：点击提交后，按钮变为 loading 状态，禁用重复提交（防抖）。
- [ ] **AC-3**：提交失败时，前端 toast 弹出明确错误，不静默吞错。
- [ ] **AC-4**：提交成功后，卡片展示「感谢反馈」并于 3 秒后自动收起。
