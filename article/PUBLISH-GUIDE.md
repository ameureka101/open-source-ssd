### C. X / Twitter 线程（8 条精炼 Thread 模版）
1. 🧵 **1/8**：为什么 AI 写的代码全跑通了，生产却崩溃了？最近我们复盘了一个案例：AI 的单测全绿，但核心逻辑其实在 `catch` 块里静默返回 `{ success: true }`，底层写入的全部是死数据。
2. 🧵 **2/8**：AI 不是不可用，而是缺少「控制面」。过去半年我们在工程实践中摸索了一套 Harness Engineering 流水线，累计完成 61 篇多维审计，揪出 444 条系统缺陷。
3. 🧵 **3/8**：核心原则 ①「禁跳步是磁盘可验证的」。任务完成当且仅当收口记录存在、状态为五态之一、回归门退出码为 0、Commit 回填。
4. 🧵 **4/8**：核心原则 ②「Markdown 即协议」。我们强制将 findings 提炼到头部 Frontmatter，实现 11.23x 的上下文压缩，告别让 Agent 每次通读万字长文。
5. 🧵 **5/8**：核心原则 ③「把人审编译进类型系统」。页面能否进 Sitemap，由 TypeScript 类型守卫 `isIndexablePage` 判定，必须具备 Owner 防伪签名，缺少即编译抛错。
6. 🧵 **6/8**：我们更公开了「机制落地率」：收口记录覆盖 100%，但 Markdown 摘要块因格式漂移仅落地 58%，教训自动回流 Skill 的闭环目前仍是 0%。敢于公开缺口，才是真实工程。
7. 🧵 **7/8**：今天我们将整套流水线协议与 4 套核心 Skills（盲区审计、需求矩阵生成、循环提示词、SSD 实施）完整开源在项目中。
