# CCAF101 视觉人格设定

> 阶段：P1 视觉人格
> 版本：v1.0
> 状态：已冻结
> 上游输入：`00-战略定义/01-品牌核心定义.md`
> 核心 IP：The Beacon Owl（灯塔猫头鹰）
> 冻结确认：2026-06-06，用户确认继续推进 P2

## 1. 核心结论

CCAF101 的核心视觉人格是：

> The Beacon Owl，灯塔猫头鹰。

它不是“认证徽章”，也不是“AI 机器人”。它是一只用 16×16 像素构成的夜视猫头鹰，核心识别点是一只琥珀色灯塔之眼。

这只眼睛代表 CCAF101 的品牌任务：在英文信息、认证路径和生产工程能力之间，为中国开发者照出第一条可走通的路。

## 2. 否定段：为什么不是这些隐喻

| 被否定的隐喻 | 否定理由 |
|---|---|
| 盾牌 / 徽章 / 证书 | 认证品牌中最常见的陈词隐喻，缺少原创性，并容易暗示官方背书或发证机构身份 |
| 学士帽 | 教育行业陈词，偏“学校/课程”，弱化生产级工程能力 |
| 机器人 / AI 脑 | 容易落入泛 AI 产品同质化，也不适合对外暴露或暗示模型身份 |
| 企鹅 | token101 专属 IP，已绑定 The Insight Penguin 和眼镜语义 |
| 灯泡 | Ameureka Bulb Bot 专属核心视觉，不应复用为 CCAF101 主符号 |
| 官方拟态图形 | 任何接近官方认证、官方徽章、官方视觉系统的符号都不使用 |

否定原则：CCAF101 不能看起来像“又一个证书品牌”，也不能看起来像“官方认证机构”。它必须是 Ameureka 体系下的原创子品牌。

## 3. 肯定段：为什么是猫头鹰

猫头鹰同时承载四个品牌价值：

1. **智慧 / 知识**
   - 对应认证学习、考域理解和训练营知识体系。
   - 不是“刷题小抄”，而是理解生产场景背后的工程判断。

2. **夜视 / 暗中视物**
   - 对应跨越语言与信息鸿沟。
   - 官方课程、英文资料、CPN 路径和工程实践都像夜里隐藏的路标；猫头鹰能在暗处看清。

3. **360° 全景视角**
   - 对应 CCA-F 五大考域和 6 个生产场景的全覆盖。
   - 不只盯一个知识点，而是能从架构、代码工作流、Prompt、MCP、Context Reliability 同时判断。

4. **夜猫子开发者文化**
   - 对应真实开发者的工作方式。
   - 深夜调试、查文档、跑实验、复盘工程失败，是这个品牌要服务的真实人群。

## 4. 核心特征：Beacon Eye

The Beacon Owl 的最高识别特征不是翅膀、爪子或羽毛，而是：

> 单只琥珀色灯塔之眼。

这只眼睛必须在 16×16 favicon 尺寸下仍然可辨认。它可以是一个或少数几个琥珀色像素点，但语义必须稳定：

- **Beacon**：照亮路径，解决信息差。
- **Amber**：认证、成就、先发之光。
- **Single Eye**：聚焦、信任入口、在复杂考域中抓住关键。

双眼猫头鹰更自然，但单只灯塔眼更强记忆点。它让 CCAF101 从普通猫头鹰中分离出来。

## 5. 特征-价值绑定表

| 可见特征 | 品牌价值 | 产品能力 |
|---|---|---|
| 紧凑直立的猫头鹰身体 | 基础、入门、完整小系统 | `101` 入门体系，小而完整 |
| 单只琥珀色灯塔之眼 | 照亮、先发、信任入口 | 跨越语言与信息鸿沟，帮助学员看清认证路径 |
| 眼睛射出或暗示光束 | 不只考过，更能上生产 | 用方法论照亮真实工程路径 |
| 耳羽或头部尖角 | 夜视、警觉、技术敏感度 | 识别考纲变化、场景边界和工程风险 |
| 栖息在像素网格线 | 工程师文化、像素基因 | 与 Ameureka / token101 的 Code-Is-Truth 资产系统同源 |
| 单色身体 + 单点琥珀 | 墨与纸克制 | 90% B&W + 7% 琥珀点缀，拒绝花哨证书风 |

## 6. 媒介决策：16×16 像素艺术

CCAF101 采用 16×16 像素艺术作为核心视觉母版。

这不是审美偏好，而是功能性决策：

### 6.1 防伪图腾

粗粝像素比常见 3D 吉祥物、渐变抽象图形、AI 生成插画更难被批量仿造。

16×16 母版的每一个像素都可解释、可审计、可复现。它是工程师图腾，不是装饰图。

### 6.2 极小尺寸保真

CCAF101 需要 favicon、社群头像、课程卡片、题库 UI、文档侧栏等小尺寸触点。

16×16 像素图在 favicon 中无需抗锯齿仍然锐利；灯塔之眼只需一个琥珀色亮点就能保留识别。

### 6.3 语义互文

CCAF 的考试结构以场景为离散意义单元：6 个预设生产场景，每次抽 4 个。

Pixel 是图像的离散视觉单元。Scenario 之于 CCAF 考卷，Pixel 之于图像。两者都是从基础单元构成完整判断。

## 7. 继承声明

CCAF101 与 Ameureka / token101 共享以下视觉工程基因：

- 16×16 像素媒介。
- Ink & Paper 的克制配色哲学。
- Code-Is-Truth 资产生成方式。
- `shape-rendering="crispEdges"`。
- 纯 Python 零依赖生成脚本。
- 用整数矩阵和颜色字典作为资产单一事实源。

但 CCAF101 必须保持独立：

| 项 | token101 | CCAF101 |
|---|---|---|
| 动物 | 企鹅 | 猫头鹰 |
| 核心特征 | 大圆眼镜 | 单只琥珀色灯塔之眼 |
| 价值重心 | AI 基础设施与保险 | CCAF 备考到生产级工程能力 |
| 主强调色 | 绿 + 橙 | 琥珀 |
| 互文结构 | Token ↔ Pixel | Scenario ↔ Pixel |

## 8. 禁用项

以下视觉元素不得用于 CCAF101 主品牌资产：

- token101 的眼镜。
- Ameureka Bulb Bot 的灯泡。
- 盾牌、徽章、证书、奖章。
- 学士帽、毕业证、教室黑板。
- 机器人、AI 脑、神经网络头颅。
- 任何与官方认证视觉相似的边框、印章、徽记、绶带。
- 紫色、蓝紫渐变、泛 SaaS 科技光效。

## 9. 冻结记录

P1 已冻结以下 4 项：

1. `The Beacon Owl` / 灯塔猫头鹰是 CCAF101 唯一核心 IP。
2. 单只琥珀色灯塔之眼是最高识别特征。
3. 16×16 像素艺术是资产母版媒介。
4. 禁用项生效：眼镜、灯泡、盾牌徽章、学士帽、官方视觉暗示、机器人/AI 脑、紫蓝科技风。
