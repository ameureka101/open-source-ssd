
- 页面 canonical / OG / JSON-LD 存在且来自集中 SEO 源。

### 8. known-traps

- **KT-012 本地通过不等于生产通过**：本地 build/curl 全绿，生产也可能仍是旧版本或缺 env。
- **KT-041 生产模拟 secret 被误认为真实配置**：build 用的临时 secret 只为消除默认 secret 风险，不能当生产密钥。
- **KT-042 表单 action 通过不等于送达闭环通过**：redirect 成功只证明 Server Action 路径通，webhook/CRM/邮件还要生产验证。
- **KT-043 只看 desktop 忽略 320px 溢出**：Stitch 可只产桌面，但 P7 必须检查移动基础可用。
- **KT-044 sitemap 范围过宽**：auth/dashboard/test 等非公开面如果进入 sitemap，就是发布面污染。
